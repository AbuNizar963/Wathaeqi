# أرشيف مخطط Supabase القديم — للرجوع التاريخي فقط

هذا المجلد يحتوي على ملفات SQL واختبارات قاعدة البيانات الخاصة بالإصدار السابق من وثائقي.

**لم يعد Supabase مزود تشغيل للتطبيق.** تم نقل واجهة المالك والمستندات النشطة إلى Appwrite، وأزيلت خطوات تشغيل Supabase من GitHub Actions واعتماد SDK من التطبيق.

- لا تشغّل `supabase start` أو `supabase db push` أو `supabase db reset` لهذا المستودع.
- لا تُستخدم ملفات هذا المجلد في بناء التطبيق أو نشره.
- لا تحذف هذه الملفات ضمن ترحيل الخدمات؛ فهي محفوظة كمرجع تاريخي لمخطط الإصدار القديم.
- لا يتضمن هذا الأرشيف بيانات المشروع أو كلمات مرور أو مفاتيح تشغيل.

أي حاجة مستقبلية إلى بيانات قديمة تتطلب قراراً مستقلاً وخطة قراءة/تصدير موثقة؛ لا تنفذ هذه الملفات أي اتصال بالمشروع الخارجي.
