# تكامل Appwrite MCP وتوافق مخطط الإعدادات

## قرار التكامل

تم تفعيل موصل Appwrite MCP الرسمي لمشروع Wathaeqi باستخدام الخادم المستضاف `https://mcp.appwrite.io/` ومصادقة OAuth. يتيح الخادم الوصول المباشر إلى مشروع Appwrite والبحث في الوثائق واكتشاف أدوات الخدمات عند الحاجة، مع فصل عمليات القراءة عن عمليات الكتابة التي تتطلب تأكيدًا صريحًا وسببًا.

اعتمد القرار على توثيق Appwrite الرسمي الذي يوضح أن الخادم المستضاف يعمل عبر HTTP، وأن أدواته تشمل الحصول على سياق المشروع والبحث عن الأدوات والوثائق وعمليات القراءة والكتابة. [1]

## معالجة خطأ مخطط الإعدادات

قد يسبق مخطط Appwrite المنشور مخطط الشيفرة لفترة قصيرة. لذلك يحاول مستودع إعدادات الوثائق حفظ البيانات كاملة أولًا. إذا أعاد Appwrite خطأ `Unknown attribute` لحقل غير منشور، تُزال السمة المرفوضة فقط وتُعاد المحاولة ببقية الإعدادات. لا تُخفى أخطاء المصادقة أو الشبكة أو الصلاحيات، ولا تُجرى أي ترقية تلقائية أو حذف لبيانات الإنتاج.

تظل القراءة متوافقة مع الإصدارات القديمة؛ فإذا غاب `documentDateFormat` تُستخدم القيمة الافتراضية الآمنة `yyyy/MM/dd`. وعند نشر الحقل في Appwrite لاحقًا، يعاد حفظه تلقائيًا من دون تغيير مسار الواجهة.

## التحقق المنفذ

- لا توجد طلبات سحب مفتوحة في مستودع `AbuNizar963/Wathaeqi`.
- نجح `pnpm check`.
- نجحت اختبارات مستودع إعدادات الوثائق وعددها 10، بما فيها اختبار إعادة المحاولة عند غياب الحقل.
- نجح `pnpm check:responsive-shell`.
- لم تُنفذ عمليات كتابة أو حذف على بيانات مشروع Appwrite أثناء التحقق.
