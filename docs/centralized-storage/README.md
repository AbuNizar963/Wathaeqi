# تخزين ملفات وثائقي عبر Appwrite Storage

**الحالة:** محول Appwrite هو المحول التشغيلي الوحيد في فرع الترحيل.

## البنية الحالية

- يستخدم الخادم `server/_core/storageProvider.ts` كواجهة موحدة لعمليات الملفات.
- ينفذ `AppwriteStorageProvider` الرفع والتنزيل والحذف وإصدار روابط وصول مؤقتة باستخدام Appwrite Storage.
- تحفظ الملفات في Bucket خاص، ويظل مفتاح الخدمة داخل الخادم أو Appwrite Function فقط.
- تُشتق هوية الملف بصورة ثابتة من مفتاح التخزين عبر SHA-256، مع التحقق من بنية المفتاح قبل الرفع.
- رفع المرفقات المصرح به يصدر JWT قصير العمر للمستخدم المقصود؛ لا يُكشف مفتاح إداري للواجهة.
- روابط التنزيل المؤقتة تصدر عند الطلب وتنتهي وفق مدة محددة.

## الإعداد

اضبط المتغيرات الخادمية التالية وفق مشروع Appwrite:

- `APPWRITE_ENDPOINT`
- `APPWRITE_PROJECT_ID`
- `APPWRITE_API_KEY`
- `APPWRITE_BUCKET_ID`

ولا تضف القيم السرية إلى Git أو متغيرات الواجهة العامة.

## ضوابط التشغيل

1. تحقق من هوية المستخدم وصلاحية الوصول قبل إصدار رابط أو JWT.
2. احتفظ بالحاوية خاصة ولا تمنح صلاحيات عامة للملفات.
3. تحقق من اسم الملف ونوع المحتوى والحجم على الخادم قبل الرفع.
4. لا تسجل محتوى الملفات أو رموز الوصول في سجلات التطبيق.
5. اختبر الرفع والتنزيل والحذف في بيئة المعاينة قبل تفعيل أي مسار إنتاجي.

## البيانات السابقة

لم تُنفذ عملية نسخ أو حذف أو تعديل لبيانات أي خدمة خارجية ضمن تنظيف المستودع. إزالة ملفات إعدادات أو ترحيلات قديمة من Git لا تغيّر البيانات الموجودة في المشاريع الخارجية.
