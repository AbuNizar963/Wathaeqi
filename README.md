# وثائقي | My Documents

منصة عربية مستقلة لإعداد الكتب الرسمية، وتنظيم الوثائق وأوراق العمل، وإدارة قوالب الطباعة والأرشفة.

## التقنية

- React + Vite + TypeScript
- Tailwind CSS 4
- Firebase Authentication, Cloud Firestore, Firebase Storage
- TipTap rich-text editor
- Netlify deployment

## البدء محلياً

يتطلب Node.js 22 أو أحدث.

```bash
npm install
npm run dev
```

## إعداد Firebase

1. أنشئ مشروع Firebase منفصلاً لهذا النظام.
2. أضف تطبيق Web من إعدادات المشروع.
3. انسخ القيم إلى ملف `.env.local` بالاستناد إلى `.env.example`.
4. فعّل Authentication ومزودي تسجيل الدخول المطلوبين، وأنشئ Firestore وStorage.
5. راجع قواعد Firestore وStorage قبل تخزين أي وثائق حقيقية.

**تنبيه:** لا تضع أسرار الخدمة أو مفاتيح Admin في متغيرات `VITE_*` أو داخل المستودع. إعداد الواجهة وحده لا يكفي لتأمين البيانات؛ يجب تطبيق قواعد وصول على مستوى المستخدم/الجهة.

## التخزين دون اتصال

تُجهّز طبقة Firestore لاستخدام التخزين المحلي الدائم عند إعداد Firebase. يحتفظ النموذج الأولي أيضاً بمسودات تجريبية في تخزين المتصفح. لا تُعد هذه المسودات نسخة احتياطية موثوقة أو مزامنة متعددة الأجهزة.

## الطباعة

المعاينة تستخدم ورقة A4 وقواعد CSS للطباعة. اختبر الطباعة مع الطابعة الفعلية وهوامشها قبل اعتماد القالب الرسمي.

## النشر على Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- أضف متغيرات Firebase إلى إعدادات البيئة في Netlify بعد تجهيز مشروع Firebase.

## حالة المشروع

هذه نقطة بداية للواجهة ومحرر المستندات. لم تُربط بعد عمليات حفظ Firestore، إدارة الحسابات، ترقيم الصادر والوارد، القوالب الإدارية، أو سياسات الأرشفة. لا تستخدم بيانات رسمية حقيقية قبل استكمال المصادقة وقواعد الأمان والنسخ الاحتياطي.

## مصدر الأجزاء المعاد استخدامها

أُعيد بناء الواجهة بهيكل مستقل، مع الاستفادة من مبادئ RTL وبعض قرارات التصميم العامة في مشروع البرقيات. لم تُنسخ شيفرة أعمال البرقيات أو خدماتها أو بياناتها أو تطبيق Flutter.
