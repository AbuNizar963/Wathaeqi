# وثائقي | My Documents

منصة عربية مستقلة لإعداد الكتب الرسمية، وتنظيم الوثائق وأوراق العمل، وإدارة القوالب والطباعة والأرشفة.

## التقنية المعتمدة

- React + Vite + TypeScript
- Tailwind CSS 4
- TipTap لتحرير المستندات
- react-to-print لطباعة صفحات A4
- Appwrite Cloud للمصادقة وقاعدة البيانات والملفات
- Netlify للاستضافة

**Firebase وSupabase غير مستخدمين في هذا المشروع.**

## البدء محلياً

يتطلب Node.js 22 أو أحدث.

```bash
npm install
npm run dev
```

## إعداد Appwrite Cloud

1. أنشئ مشروعاً مستقلاً في Appwrite Cloud.
2. أضف Web Platform إلى المشروع مع نطاقات التطوير والنشر المصرح بها.
3. انسخ `.env.example` إلى `.env.local` واملأ معرّف المشروع ونقطة الاتصال.
4. أنشئ قاعدة بيانات ومجموعات المستندات والقوالب والجهات، وأنشئ Storage Bucket للمرفقات.
5. ضع معرّفات الموارد في متغيرات البيئة المقابلة.
6. اضبط صلاحيات الوصول على مستوى المستخدم أو الفريق، وامنع القراءة والكتابة العامة للوثائق الرسمية.
7. اختبر تسجيل الدخول والصلاحيات والرفع والتنزيل قبل إدخال أي بيانات حقيقية.

لا تضع مفاتيح API ذات الصلاحيات الإدارية أو أسرار الخادم في متغيرات `VITE_*` أو في المستودع. هذه المتغيرات تُضمّن في تطبيق المتصفح، ويجب أن تحتوي فقط على معرّفات إعدادات عامة.

### حالة التكامل

تمت إضافة عميل Appwrite موحداً وقراءة إعدادات الاتصال ومعرّفات الموارد من متغيرات البيئة. لم تُستكمل بعد عمليات المصادقة الفعلية، ولا CRUD للمستندات، ولا صلاحيات قواعد البيانات والتخزين. لا تعتبر المسودات الحالية مزامنة سحابية؛ فهي ما زالت محفوظة محلياً في المتصفح إلى حين تنفيذ طبقة البيانات واختبارها.

## الطباعة

تستخدم واجهة التحرير `react-to-print` لطباعة عنصر المستند وحده بدلاً من طباعة واجهة التطبيق. اختبر قوالب A4 مع مستند من صفحة واحدة وآخر متعدد الصفحات قبل اعتمادها رسمياً.

## النشر على Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- أضف متغيرات Appwrite العامة نفسها في إعدادات بيئة Netlify.
- أضف نطاق موقع Netlify إلى Web Platforms المصرح بها في Appwrite.

## الأمان والبيانات

المستودع الحالي نقطة بداية تطويرية. لا تستخدم وثائق رسمية حقيقية أو بيانات شخصية قبل إتمام المصادقة، وقواعد الوصول، وسجل التدقيق، والنسخ الاحتياطي، واختبارات الاستعادة. تأكد من ضبط خصوصية المستودع قبل رفع أي ملفات أو بيانات حساسة.
